# Contributing

Thank you for helping improve Mailrith's public agent platform.

1. Open an issue for a contract or behavior change before doing substantial work.
2. Keep public API, SDK, MCP, CLI, Agent Skill, and documentation changes synchronized.
3. Never add secrets, private Mailrith application code, customer data, database exports, or internal infrastructure configuration.
4. Run `pnpm validate` before opening a pull request.
5. Explain permission, approval, retry, idempotency, performance, and compatibility effects in the pull request.

Security reports belong in the private process described in [SECURITY.md](SECURITY.md), not a public issue.
