# Changelog

## 0.1.0 - 2026-07-24

- Request the workspace and Subscriber read permissions required by the default read-only starter.
- Document the 20-subscription workspace limit for Webhook subscription creation.
- Use task-focused resource, subscription, bulk-operation, and Webhooks Read or Write permissions.
- Remove tools for recommendation records, reference experiments, and generic compliance events.
- Publish the first stable local and self-hosted MCP server.
- Add exact generated schemas, focused toolsets, risk annotations, OAuth discovery, and structured errors.
- Use the stable MCP TypeScript SDK with a stateless Web Standards transport for hosted requests.
