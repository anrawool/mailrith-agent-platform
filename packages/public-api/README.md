# Mailrith Public API Contract

The versioned contract shared by Mailrith's REST API, OAuth server, generated SDKs, MCP server, CLI, Agent Skill, and documentation.

Most integrations should install `@mailrith/sdk` or connect to the hosted MCP server instead of importing this lower-level package.

See [Mailrith Developer Docs](https://mailrith.com/developers) for current guidance.
