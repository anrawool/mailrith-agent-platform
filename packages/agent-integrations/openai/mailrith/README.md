# Mailrith Plugin

Connect Mailrith once with OAuth, then use focused tools to review Subscribers
and reports, prepare and deliver Broadcasts, and manage Sequences, Automations,
targeting, and email Templates.

The plugin connects only to `https://api.mailrith.com/mcp`. It does not contain
an API key, access token, or workspace identifier.

## Connect Mailrith

1. Install the Mailrith plugin.
2. Choose **Connect** when ChatGPT or Codex asks you to connect Mailrith.
3. Sign in to Mailrith.
4. Choose one workspace.
5. Review the requested permissions and select **Allow Access**.

Use the Mailrith app to change or revoke the connection under
**Integrations → Authorized Apps**.
