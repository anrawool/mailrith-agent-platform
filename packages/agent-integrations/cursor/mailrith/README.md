# Mailrith For Cursor

The Mailrith plugin adds the official Mailrith Agent Skill and connects Cursor
to `https://api.mailrith.com/mcp`.

## Connect Mailrith

1. Install the plugin from Cursor Marketplace or load it from Cursor's local
   plugin folder.
2. Open Cursor settings and select **MCP**.
3. Find **mailrith** and select **Connect**.
4. Sign in to Mailrith, choose one workspace, review the permissions, and
   select **Allow Access**.
5. Return to Cursor and confirm that the server and its focused tools are
   available.

No credential is stored in this plugin. Cursor completes OAuth directly with
Mailrith.
