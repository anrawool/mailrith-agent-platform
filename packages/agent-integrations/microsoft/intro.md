# Mailrith Email Marketing

Mailrith helps teams manage Subscribers and run email marketing from one
workspace. This connector lets Microsoft agents review email results, prepare
Broadcasts, and manage Sequences, Automations, targeting, and email Templates.

## Before You Connect

You need a Mailrith account and access to the workspace you want to connect.
Your Mailrith role and the permissions you approve control what the agent can
read or change.

## Connect Mailrith

1. In Microsoft Copilot Studio, open the agent that should use Mailrith.
2. Open **Tools**.
3. Select **Add a tool**.
4. Find and select **Mailrith**.
5. Select **Connect**.
6. Sign in to Mailrith.
7. Choose one workspace.
8. Review the requested permissions.
9. Select **Allow Access**.
10. Return to Copilot Studio and confirm that the Mailrith tools are
    available.

## Use Mailrith Safely

- Ask the agent to review the connected workspace before it starts.
- Prepare drafts and run preflight before scheduling or sending a Broadcast.
- Review the exact Subscriber, Segment, Sequence, or Automation before making
  a live change.
- Keep result pages small unless you need a larger report.
- Revoke access in Mailrith under **Integrations → Authorized Apps** when the
  connection is no longer needed.

## Known Issues And Limitations

- One connection works with one Mailrith workspace. Connect again to work in a
  different workspace.
- Available actions depend on the Mailrith role and permissions approved
  during sign-in.
- Billing, team administration, account security, and delivery credentials
  are not available through this connector.
- Some changes, including sending, scheduling, activation, deletion, and
  Subscriber delivery-status changes, require explicit approval.
